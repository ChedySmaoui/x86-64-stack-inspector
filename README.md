# x86-64 Stack Frame Inspector

A systems programming project exploring function calls and stack memory
using C and inline x86-64 assembly in AT&T syntax.

## Features

- Retrieves caller base pointers and return addresses.
- Prints stack frame contents as hexadecimal values and individual bytes.
- Demonstrates stack behaviour through recursive factorial calculations.
- Includes annotated assembly and analysis of program output.
- Checks return addresses against disassembly using objdump.

Designed for an x86-64 environment; stack layout depends on compiler settings.

Developed for CS2002 at the University of St Andrews.
